Component

NgxDomConfettiComponent

Standalone component. Import it into your component's imports and use the ngx-dom-confetti selector.

active: boolean
Defaults to false. A false → true transition launches a burst; set it back to false before triggering another. Supports boolean attribute coercion.
config: Partial<ConfettiConfig> | null
Optional configuration input. Updates merge into the component's previous configuration, starting with any injected global configuration. Omitted fields retain their previous values; null does not reset them.

Directive

NgxConfettiDirective

Standalone directive with selectors [ngxConfetti] and [confetti]. Exported as ngxConfetti for template references.

launch(config?: Partial<ConfettiConfig>): void
Launches from the host element outside Angular's zone. Runs only in the browser. Without an argument, uses injected global configuration or the library defaults.
{{ directiveExample }}

Service

NgxDomConfettiService

Register the service and its configuration provider before injecting it. It is not automatically provided in root.

open(el: HTMLElement | ElementRef, config?: Partial<ConfettiConfig>): void
Launches from an HTML element or Angular element reference. Without a configuration argument, uses the injected global configuration. The method does not return an animation-completion promise.

Configuration

ConfettiConfig

The component and launch methods accept partial configurations. The values below come from the exported defaultsConfettiConfig object.

Configuration precedence

For service and directive calls, passing a configuration uses that object instead of the global configuration. Missing fields then fall back to library defaults. Component configuration updates are cumulative.

Setup

Providers & module

provideConfetti(config?: ConfettiConfig): EnvironmentProviders
Registers the global configuration token in application or route environment providers. Omit the argument to use library defaults. This helper does not register the service and does not merge a supplied configuration with defaults.
NGX_CONFETTI_GLOBAL_CONFIG: InjectionToken<ConfettiConfig>
The injection token read by the component, directive, and service for global settings.
defaultsConfettiConfig
The exported default configuration object. Copy it when building a custom configuration rather than mutating it.
NgxDomConfettiModule
Imports and exports the component and directive, and provides the service and default configuration. Both forRoot() and forChild() return ModuleWithProviders<NgxDomConfettiModule> and register those same providers.
